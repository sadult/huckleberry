Huckleberry v0.3.1
Changes save automatically

AI providers

Add real API keys, test them in one click, and choose which provider answers your questions. Keys are stored only in this browser profile and are sent nowhere except to the provider you select.

Configured providers

Add a provider
Pick a preset to fill in the endpoint and model, or configure any OpenAI-compatible service yourself.

AI engine

Answer questions through a provider API, or through a browser tab you are already logged into. Tab mode needs no API key at all.

Stay logged in to that site. Huckleberry types the question into the composer and reads the reply back.

Stall recovery

Questionnaire memory

Describe the questionnaire once. The text below is sent with every question, so the AI keeps the same persona and rules for the whole run.

Plain language works best. Keep it short and factual.

Telegram remote control

Optional. Get progress alerts and drive a run from your phone — including answering the question the AI got stuck on.

Setup

  1. Open @BotFather in Telegram and send /newbot. Copy the token it gives you.
  2. Send any message to your new bot so it can reply to you.
  3. Get your numeric chat ID from @userinfobot, paste both values above, then send the test message.

Commands

  • /listlist saved macros
  • /run 1run a macro by number or name
  • /skip 1run and jump straight to the questions
  • /statuscurrent run status
  • /answer textanswer the question the AI got stuck on
  • /retryask the AI again for that question
  • /nextconfirm and continue with the next questionnaire
  • /stopstop the run

Run behavior

Timing and reliability controls for the replay engine. The defaults suit most questionnaires.

Give slow pages more time to react.
Safety limit for question loops.
The main cause of tab mode freezing is a long chat thread. 5 works well; 0 disables recycling.

Data

Everything lives in this browser profile. Nothing is uploaded anywhere.

Backup

Exports contain macros only — never your API keys.

Danger zone

Erasing removes macros, settings, API keys and history from this profile.
