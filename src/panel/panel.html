Activity

    Stored locally in chrome.storage.local. Credentials are typed into the site itself and are never sent anywhere else.

    Commands
    • /runautopilot on the active tab
    • /stopabort the current run
    • /statusstate, stats, model
    • /ask …one-off question
    • /open urlopen a tab
    1. Pick the brain. AI tab → provider, key, model → Test connection.
    2. Teach it a site. Sites tab → host plus username and password. Add CSS selectors only if auto-detection misses.
    3. Run. Open the page and press Run autopilot. Detected blocks glow violet, answered ones turn green.
    4. Go remote. Telegram tab → token → send /run from your phone.
    Troubleshooting
    • 0 detectedpage renders late; scroll once, then Scan
    • no matching choicelower temperature or keep the verbatim rule in the prompt
    • HTTP 400model name not valid for the provider; press Load models
    • HTTP 401 / 403wrong key, or key not enabled for that API
    • HTTP 429rate limited; Huckleberry retries with backoff
    • iframeruns in all frames; click inside the frame first
